# 🥋 Analytics Combat

Primer proyecto del grupo de Sports Analytics, enfocado en el análisis de datos de deportes de combate (como taekwondo, MMA, boxeo). El objetivo es medir el rendimiento técnico, tiempos de reacción, frecuencia de golpeo y progresión de los atletas para generar ventajas competitivas mediante el uso de datos.

## 🎯 Objetivos del Proyecto
1.  **Recolección Estandarizada:** Definir métricas clave y establecer un formato riguroso para la recolección de datos técnicos y físicos.
2.  **Análisis Descriptivo y Diagnóstico:** Identificar patrones de éxito y áreas de mejora en los atletas mediante estadística descriptiva.
3.  **Visualización (Data Storytelling):** Construir dashboards interactivos en Power BI para comunicar hallazgos a entrenadores y deportistas de forma intuitiva.

## 👥 Equipo de Trabajo
*   **Líder de Proyecto:** Arquitectura de datos, definición de métricas, revisión de código y diseño avanzado en Power BI.
*   **Asistente 1 (Data Prep):** Digitación, limpieza y estructuración de los datasets (Pandas, Excel).
*   **Asistente 2 (Exploración):** Análisis exploratorio de datos (EDA), estadística descriptiva y detección de valores atípicos.
*   **Asistente 3 (Visualización):** Construcción de gráficos preliminares, apoyo en documentación y diseño base.

## 📂 Estructura del Directorio
*   `/data`: Datasets crudos y procesados (`.csv`, `.json`). **Nota:** No subir datos sensibles de atletas sin anonimizar.
*   `/scripts`: Scripts de Python para ETL y análisis.
*   `/dashboards`: Archivos `.pbix` (Power BI) y plantillas.
*   `/docs`: Diccionarios de datos y manuales de recolección.
*   `kanban.html`: Aplicación local para la gestión ágil de tareas del equipo (Sprints).

## 🚀 Flujo de Trabajo (Sprint 1)
1.  Definición de variables y entrega de plantilla de recolección.
2.  Levantamiento de datos de prueba (mock data o videos históricos).
3.  Limpieza de datos mediante scripts colaborativos.
4.  Creación del primer dashboard descriptivo.
